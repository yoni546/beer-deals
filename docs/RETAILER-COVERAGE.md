## Root causes (each traced to the stage that dropped the rows)

1. **NORMALIZE / PACK — multipacks with no container word were held.** Rami Levy (and several others) write
   multipack names without "בקבוק"/"פחית" and cut at 20 characters ("בירה גולדסטאר שישייה"). The pack (count ×
   size) was read correctly but the row was HELD for "container unknown" — every Rami Levy six-pack was dropped,
   and with them every promotion on them ("none of its items is a pack we could read"). Now the container is
   published as *not stated* (`other`; the label shows only what is known) — never guessed.
2. **NORMALIZE — one unit's size in Quantity.** Rami Levy writes the size of ONE can in `Quantity` on a
   six-pack ("בירה בדוויזר שישייה", 330 per 100 ml). Read as 6 × 330, marked *partial*, with the reason kept.
3. **NORMALIZE — Hatzi Hinam leaves the unit empty** and writes millilitres ("500"). A number that is exactly a
   standard single size is read as that size when there is no unit at all; anything else stays unknown.
4. **SKU MATCH — a row whose text does not say the pack** ("בירה קרלסברג שישייה", Quantity "2") now takes the
   pack every other reading of the same barcode agrees on (a barcode is one physical product), and only when
   the price is believable for that pack. Two item codes at one price for the same pack collapse to one listing.
5. **PROMOTION VALIDATION — over-filtering.** A promotion was published only when the description AND
   `DiscountedPrice` stated the same price. Yochananof never writes the price in the description: all 21 of its
   public beer promotions were held. Now one statement is enough when a second, independent one confirms it —
   the branch's own shelf price for every item it covers (a real saving, not more than 70%). One price for
   several packs ("קרלסברג/טובורג שישייה ב־29.90") is one promotion per pack; items we could not read are left
   out of an offer instead of holding it.
6. **CATALOGUE — beers we did not carry.** Krombacher (8 chains), Eagle (7), 1664 (6), Miller, Staropramen,
   La Chouffe, Kasteel (5 each), Hoegaarden, Franziskaner, Estrella Damm, Blue Moon, Benediktiner were read and
   discarded as "a beer the app does not carry" — and every promotion that named them with them. Added in
   migration 0016 with identities and (8 of 12) real bottle photos. Maccabee 7.9% and Budweiser Dark are now
   variants (they were colliding with Maccabee / Budweiser and both rows were held).
7. **FETCH — Victory and Mahsanei HaShuk (Laib Catalog).** The fetcher posted the site's ASP.NET search form,
   which answers automated requests with an empty table, so Victory never had a single row. The page is fed by
   a public JSON API (`/webapi/api/getfiles?edi=<chain>` → `/webapi/<chain>/<file>`), which the fetcher now
   reads: Victory 45 regular prices and 28 public promotions on one branch. The API lists only the current
   Israeli day's files, so right after midnight it is empty until the chains publish (then retry).
